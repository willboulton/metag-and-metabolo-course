## Overview

This module covers the integrated statistical analysis in R, taking the processed metagenomic abundance tables and metabolomics feature matrix from the Workflow module and producing diversity statistics, co-occurrence networks, differential abundance results, and biologically interpretable figures.

For those of you on the GIBA course, this is day 4 of the course. 

You can use the data in [this Figshare repository](https://doi.org/10.6084/m9.figshare.29860841) as a starting point; if you did not manage to run MATAFILER4, or analyse the metabolomics data from scratch, do not worry because you can now start afresh and follow along using these preprocessed data. 

We'll analyse the data using R, but the codes to reproduce figures from the paper are also available in [this github repository](https://github.com/apduncan/dime_analysis). We'll be reproducing a few of the key figures using very similar code to what's in this repository. If you glance through this github repository, you'll find a folder called `tutorial files`... this is what we'll be following. 

Browsing the repository a bit further, and you might notice that in total it is several thousand lines of quite difficult R code. This is a bit too much to replicate in a single tutorial. 
To simplify life quite considerably, we'll focus on a smaller metabolomics and metagenomics dataset: 

 - We'll use simplified abundance tables of MGS, already normalised for us in RPM
 - We'll only use the targeted metabolomics data, which is just a table of SCFAs concentrations per sample
 - We'll correlate these data with a single set of nutrient intake data that focusses on bioactive concentrations

Even with these caveats, this is the most difficult part of the course and will feature a lot of code.

## Session Zero - Installing Packages

To get the easy bit out of the way first, try installing the packages necessary for the analysis. 
You'll also need to clone the github repository for [DIME](https://github.com/apduncan/dime_analysis) since we use a few helper functions from there, to save some time writing code. Finally, you'll need the raw data - download that from [figshare](https://doi.org/10.6084/m9.figshare.29860841). 

Code to install packages is below: 

```r
# packages for the numerical ecology / differential abundance sections
install.packages(c(
                   "rtk", "ggplot2", "ape", "vegan", "cowplot",
                   "data.table", "minpack.lm", "Hmisc", "reshape2",
                   "tidyverse", "scales", "coin", "nlme", "compositions",
                   "FSA", "ggvenn", "rstatix"))

install.packages("remotes")
remotes::install_github("DanielSprockett/reltools")

if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}

BiocManager::install(c("phyloseq", "DESeq2", "decontam", "microbiome"))
```

```r
# packages for the network analysis section
install.packages(c("igraph", "pheatmap", "ggrepel", "readxl", "ggpubr"))

# the dev version installs properly on R 4.5.2
remotes::install_github("zdk123/SpiecEasi@devel")

# and we need an old version of NetCoMi...
```
