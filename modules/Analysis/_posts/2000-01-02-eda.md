## 7  Genus–bioactive correlations

Finally, we test whether individual genera correlate with bioactive intake. We compute
Spearman correlations between each (genus, bioactive) pair, 
correct for multiple testing, and display genera with at least one significant association.

### 7.1  Align matrices

```r
# Bioactive intake matrix: bioactives on rows, samples on columns
bio_mat <- lst_diet$bioactive

# Restrict to samples present in both matrices
sample_ids <- tbl_md$sample_id
sample_ids <- intersect(sample_ids, colnames(bio_mat))

genus_filt   <- genus_rel[top_genera, sample_ids]   # top genera x samples
bio_all     <- bio_mat[, sample_ids]               # bioactives x samples

cat(nrow(genus_filt), "genera x", nrow(bio_all), "bioactives across",
    length(sample_ids), "samples\n")
```

```
## 30 genera x 27 bioactives across 60 samples
```

### 7.2  Compute correlations and p-values

```r
# Build all (genus, bioactive) pairs and run cor.test() on each
pairs <- expand.grid(
  genus    = rownames(genus_filt),
  bioactive = rownames(bio_all),
  stringsAsFactors = FALSE
)

corr_results <- mapply(
  FUN = function(g, b) {
    res <- cor.test(
      as.numeric(genus_filt[g, ]),
      as.numeric(bio_all[b, ]),
      method = "spearman"
    )
    c(rho = unname(res$estimate), pval = res$p.value)
  },
  pairs$genus, pairs$bioactive,
  SIMPLIFY = TRUE
) |> t() |> as.data.frame()

pairs$rho  <- corr_results$rho
pairs$pval <- corr_results$pval
pairs$qval <- p.adjust(pairs$pval, method = "BH")

# How many significant pairs?
sum(pairs$qval <= 0.05)
```

```
## [1] 0
```

So after taking into account multiple testing, there aren't any significant associations. 

### 7.3  Heatmap of significant genera

```r

# There are too few genera with a significant q-value, let's just use p-values for this tutorial. 
message("Too few genera pass q <= 0.05 — relaxing to p <= 0.05 for illustration")
sig_genera <- pairs |> filter(pval <= 0.05) |> pull(genus) |> unique()

# Build rho matrix and significance label matrix for significant genera
tbl_sig <- pairs |> filter(genus %in% sig_genera)

rho_mat <- tbl_sig |>
  pivot_wider(id_cols = genus, names_from = bioactive, values_from = rho) |>
  column_to_rownames("genus") |>
  as.matrix()

sig_labels <- tbl_sig |>
  mutate(label = case_when(
    qval  <= 0.05 ~ "**",
    pval  <= 0.05 ~ "*",
    TRUE          ~ ""
  )) |>
  pivot_wider(id_cols = genus, names_from = bioactive, values_from = label) |>
  column_to_rownames("genus") |>
  as.matrix()

# Rename genera to short names for readability
rownames(rho_mat)   <- map_chr(rownames(rho_mat), trim_to_genus)
rownames(sig_labels) <- rownames(rho_mat)

pheatmap::pheatmap(
```

## Recap

We've done a lot of exploring the data. This is useful because in the next sessions we'll be looking at much more 
abstract / complicated analyses. So, you'll likely want to relate what you see in those analyses back to this
much simpler analysis where you're looking at a 'raw' version of the data. 

| Step | Function | What it does |
|---|---|---|
| Relative abundance | `prop.table(margin = 2)` | Converts read counts to per-sample proportions |
| Pivot to long form | `pivot_longer()` | Reshapes wide matrix to ggplot-friendly format |
| Wilcoxon signed-rank | `ggpubr::stat_compare_means(paired = TRUE)` | Pairwise test on paired (crossover) samples |
| Heatmap | `pheatmap::pheatmap()` | Clustered heatmap with optional cell annotations |
| Pairwise correlations | `cor.test(method = "spearman")` | Spearman rho + p-value per pair |
| Multiple testing | `p.adjust(method = "BH")` | Benjamini–Hochberg FDR correction across all pairs |
