## Setting Up the Workshop Environment

Install every package this module needs. Run this once, top to bottom. Not everything lives on CRAN — some come from Bioconductor, and `microViz` comes from R-universe.

This module uses R 4.5.2, on JupyterHub or a local conda/micromamba environment.

### Where the Packages Come From

| Source | Packages |
|----|----|
| **CRAN** | vegan, ape, dplyr, ggplot2, cowplot, ggrepel, rtk, dunn.test |
| **Bioconductor** | phyloseq, decontam, microbiome, ALDEx2, ComplexHeatmap |

### Checker

Only feed the installers the packages that aren't already present.

```r
options(repos = c(CRAN = "https://cloud.r-project.org"))

need <- function(pkgs) pkgs[!pkgs %in% rownames(installed.packages())]
```

### CRAN Packages

```r
cran_pkgs <- c("vegan", "ape", "dplyr", "ggplot2",
               "cowplot", "ggrepel", "rtk", "dunn.test", "BiocManager")

to_get <- need(cran_pkgs)
if (length(to_get)) install.packages(to_get)
```

### Bioconductor Packages

`BiocManager` picks the Bioconductor release that matches your R version automatically — no need to name it.

```r
if (!requireNamespace("BiocManager", quietly = TRUE)) install.packages("BiocManager")

bioc_pkgs <- c("phyloseq", "decontam", "microbiome", "ALDEx2", "ComplexHeatmap")

to_get <- need(bioc_pkgs)
if (length(to_get)) BiocManager::install(to_get, update = FALSE, ask = FALSE)
```

### microViz (Optional Extra)

We won't use `microViz` in this module, but it's worth checking out - it isn't needed if you're following along on JupyterHub.

**Not on CRAN.** Install from the maintainer's R-universe. If that ever fails, the commented GitHub route does the same thing (needs `remotes`).

```r
if (!requireNamespace("microViz", quietly = TRUE)) {
  install.packages("microViz",
    repos = c(davidbarnett = "https://david-barnett.r-universe.dev",
              getOption("repos")))
}

# Fallback:
# if (!requireNamespace("remotes", quietly = TRUE)) install.packages("remotes")
# remotes::install_github("david-barnett/microViz")
```

### Verify

Everything should read `TRUE`. Anything `FALSE` didn't install — scroll up for its error.

```r
all_pkgs <- c(cran_pkgs, bioc_pkgs)
data.frame(package   = all_pkgs,
           installed = vapply(all_pkgs, requireNamespace, logical(1), quietly = TRUE),
           row.names = NULL)
```
